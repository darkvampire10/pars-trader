# نصب نسخه ۰.۱

## پیش‌نیاز

- Linux با Docker Engine و Docker Compose؛ نصب از https://docs.docker.com/engine/install/
- دسترسی خروجی HTTPS به Telegram و سرویس‌های داده
- توکن ربات ساخته‌شده توسط خودتان در BotFather و شناسه عددی تلگرام مالک
- فقط یک نمونه فعال از این سرویس برای هر توکن

برای آزمایش اولیه این سرویس سبک است؛ نیاز منابع MT5/Wine باید روی سرور منتخب سنجیده شود. خرید VPS ویندوزی در این مرحله الزامی نیست.

## دریافت کد

پس از ساخته‌شدن مخزن، آدرس واقعی آن را جایگزین کنید. این راهنما ادعا نمی‌کند مخزن از قبل منتشر شده است.

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL> pars-trader
cd pars-trader
bash scripts/install.sh
```

اولین اجرا فقط `.env` می‌سازد. فایل را روی سرور ویرایش کنید:

```bash
nano .env
```

`TELEGRAM_BOT_TOKEN` و `TELEGRAM_OWNER_ID` را مقداردهی کنید. رمز یا توکن را در چت، issue یا commit نفرستید.
برای یافتن شناسه، می‌توانید پس از ارسال `/start` به ربات خودتان، پاسخ `getUpdates` API تلگرام را به‌صورت محلی بررسی کنید؛ این پاسخ خصوصی است.

```bash
mkdir -p data
sudo chown -R 10001:10001 data
bash scripts/install.sh
docker compose logs --tail=50 bot
```

ربات را با `/start` باز کنید و `/plan` بفرستید. پیش‌فرض متوقف است. `/signals` پایش را آغاز می‌کند.
هیچ پورت عمومی باز نمی‌شود؛ Telegram از long polling استفاده می‌کند.

## تأمین قیمت

`scripts/mt5_export.py` فقط قیمت را می‌خواند و سفارش ارسال نمی‌کند.
در محیط Windows Python کنار ترمینال MT5، بسته رسمی `MetaTrader5` را نصب کنید.
متغیرهای خصوصی `MT5_LOGIN`، `MT5_PASSWORD`، `MT5_SERVER`، `DATA_DIR` را همان‌جا تنظیم کنید.
نام سرور باید دقیقاً همان نام موجود در ترمینال باشد؛ نام برند FeneFX لزوماً کافی نیست.
نمادهای دارای پسوند را با `MT5_SYMBOL_MAP` نگاشت کنید؛ نمونه:

```json
{"XAUUSD":"XAUUSD.a","EURUSD":"EURUSD.a"}
```

این فقط مثال است؛ نام نماد بروکر شما تأیید نشده است.

در Linux، ترمینال MT5 از Wine استفاده می‌کند. خود اسکریپت پل باید در محیط سازگار با بسته Windows اجرا شود؛ نصب بسته Python لینوکس جای آن را نمی‌گیرد.
اجرای دائمی Wine، نمایشگر مجازی، ورود حساب و بازیابی پس از قطع باید جداگانه آزمایش شوند.
راهنمای رسمی: https://www.metatrader5.com/en/terminal/help/start_advanced/install_linux

فایل `market.json` باید اتمیک در `data/` جایگزین شود، مالک مناسب داشته باشد و ساعت دو محیط با UTC همگام باشد.
در سرور مجزا، انتقال با SSH انجام شود؛ پورت عمومی برای فایل قیمت نسازید.

## تقویم خبری

نسخه اول دریافت‌کننده خبر تجاری ندارد. سرویس انتخابی بعدی باید قرارداد زیر را به `data/calendar.json` بنویسد:

```json
{
  "generated_at": 0,
  "coverage_start": 0,
  "coverage_end": 0,
  "currencies": ["XAU", "USD", "EUR"],
  "events": [{"time": 0, "currency": "USD", "impact": "high"}]
}
```

صفرها مثال قالب‌اند و **عمداً معتبر نیستند**. زمان‌ها UTC Unix هستند.
فایل باید حداکثر یک ساعت قدیمی باشد و پوشش حداقل ۱۵ دقیقه قبل و بعد از زمان فعلی را اعلام کند.
آرایه خالی اخبار را فقط وقتی بنویسید که منبع واقعی نبود خبر را تأیید کرده باشد.
در نبود این شرایط ربات سیگنال نمی‌دهد. این رفتار خطا نیست.

## محدودیت فعلی

موجودی `/balance` فقط سرمایه آزمایشی است. اتصال موجودی واقعی، محاسبه حجم در پیام، فرم HTTPS رمز، API هوش مصنوعی و اجرای خودکار در نسخه بعدی توسعه می‌یابند.
تست محلی جای تست اتصال Telegram، MT5 یا اجرای Docker روی سرور را نمی‌گیرد.
