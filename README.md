# Pars Trader | پارس تریدر

ربات متن‌باز تلگرام برای پژوهش استراتژی اسکالپ طلا و جفت‌ارزهای دلار.
مجوز MIT؛ مستقل از FeneFX و بدون وابستگی تجاری به آن.

## وضعیت واقعی نسخه 0.1.0

این نسخه یک پایه قابل نصب و توسعه است، نه محصول نهایی معامله خودکار.

| قابلیت | وضعیت |
|---|---|
| ربات فارسی تک‌کاربره، انتخاب پلن، توقف، وضعیت و تاریخچه | پیاده‌سازی شده؛ اتصال واقعی تلگرام نیازمند توکن شماست |
| تشخیص شکست و پولبک با کندل بسته‌شده | پیاده‌سازی و تست مصنوعی؛ سودآوری ارزیابی نشده |
| سیگنال ورود، SL و TP1/2/3 از فایل قیمت تازه | پیاده‌سازی شده؛ داده MT5 و تقویم باید تأمین شوند |
| شبیه‌ساز سه خروج و استاپ ورود | پیاده‌سازی شده؛ مدل ساده بدون هزینه و نه بک‌تستر کامل |
| محاسبه حجم و ظرفیت ریسک | توابع تست‌شده؛ هنوز به حساب واقعی متصل نیست |
| خواندن قیمت از MT5 | اسکریپت اختیاری read-only؛ روی بروکر کاربر آزمایش نشده |
| Docker، CI، راهنمای نصب، به‌روزرسانی و بازگشت | فایل‌ها آماده؛ اجرای Docker در محیط ساخت انجام نشده |
| معامله واقعی، بستن سفارش، فرم امن رمز | **پیاده‌سازی نشده**؛ `/live` امکان فعال‌سازی ندارد |
| اخبار خودکار و تحلیل AI | **پیاده‌سازی نشده**؛ فعلاً قرارداد فایل تقویم با توقف در نبود داده |
| چندکاربره، پرداخت اشتراک، داشبورد | در نقشه راه |

بدون داده معتبر، ربات هیچ سیگنالی نمی‌سازد. دمو از قیمت‌های ساختگی استفاده می‌کند و سیگنال بازار نیست.

## اجرای فوری بدون کلید و بدون شبکه

به Python 3.11 یا جدیدتر نیاز دارید. از پوشه پروژه:

```bash
python3 -m unittest discover -s tests -v
python3 -m pars_trader demo
```

خروجی دمو سه تارگت 101، 102، 103 و سود ناخالص 2R برای سه خروج مساوی است.

## نصب روی سرور

راهنمای فارسی: [INSTALL.fa.md](docs/INSTALL.fa.md).
برای به‌روزرسانی و بازگشت: [UPDATES.fa.md](docs/UPDATES.fa.md).
فایل‌های محرمانه `.env` و `data/` هرگز وارد Git نمی‌شوند.

## ساختار

- `pars_trader/core.py`: محاسبه ریسک و شبیه‌ساز خروج
- `pars_trader/strategy.py`: تشخیص ستاپ بدون کندل آینده
- `pars_trader/news.py`: کنترل تازگی و پوشش تقویم
- `pars_trader/scanner.py`: تبدیل داده به ستاپ پژوهشی
- `pars_trader/telegram.py`: فرمان‌ها و محدودسازی به مالک
- `pars_trader/app.py`: پایش و دریافت فرمان تلگرام
- `scripts/mt5_export.py`: خروجی قیمت MT5 بدون ارسال سفارش
- `docs/`: نصب، توسعه، قوانین و محدودیت‌ها
- `AGENTS.md`: راهنمای ادامه توسعه با Codex یا ابزارهای دیگر

## ادامه توسعه

برای هر تغییر یک شاخه و Pull Request ایجاد کنید، تست‌ها را اجرا کنید و نسخه منتشر کنید.
به‌روزرسانی از GitHub خودبه‌خود روی VPS اجرا نمی‌شود؛ اسکریپت به‌روزرسانی نسخه مشخص می‌گیرد.
هدف‌ها و شرایط آماده‌بودن معامله واقعی در [ROADMAP.md](docs/ROADMAP.md) آمده‌اند.

هیچ بازده، پاس‌شدن پراپ یا جلوگیری قطعی از زیان تضمین نمی‌شود. انتخاب پلن در ربات به معنی احراز مجوز EA نیست.
